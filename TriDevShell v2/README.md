# Welcome to TriDev Shell 2.0 (Dev Environment)

If you are reading this, welcome! You are most likely here to contribute. If yes, then please read the rules below. 

If you are just here because you want to see the code before downloading it, feel free to look around!

---

## Rules for Contributing

Look, I am not going to be strict. Just add whatever good command you think would suit the shell, or fix a bug that bothers you. 

Please don't mess up anything that works perfectly already. Of course, I will personally review all pull requests, but still—keep it nice.

The only 4 rules are these:

1. **Use comments:** Separate logic inside files like how I did.
2. **Document your code:** Always use JSDoc or clear inline comments.
3. **Keep commands organized:** If you add a new command, always name the main handler `exampleCommand` and import it to `index.js` the same way I do.
4. **No AI slop:** Don't use AI to write the code for you. If you need help conceptualizing or debugging, use it as a tool, but write the final code yourself. I want this repo to be human-built.
